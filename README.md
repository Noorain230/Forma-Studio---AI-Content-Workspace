# Forma-Studio---AI-Content-Workspace
A web-based prompt engineering studio that features real-time response streaming and session management.

## Fetures
- **Real-time Response Streaming:** Generates and displays AI responses dynamically.
- **Session Management:** Saves user data and chat history locally using browser LocalStorage.
- **Custom AI Connection:** Users can input their own API keys and choose specific chat completion models directly from the UI.
- **privacy First:** No backend server is used; API keys are processed entirely on the client side and not stored in any external database.

## Technologies Used
- HTML%5
- CSS3
- Vanilla JavaScript
- REST APIs
- LocalStorage

## Installation and Setup
Since this is a client-side application, no complex installation or environment variables are required.
1. Clone the repository:
2. Open the project folder
3. Double-click 'index.html' to open the application in your default web browser.
